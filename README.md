# RentIA

**RentIA** est un projet personnel de plateforme intelligente de gestion locative destiné principalement aux propriétaires et gestionnaires de petits et moyens parcs immobiliers.

L’objectif est de centraliser les informations liées aux logements, aux locataires, aux baux, aux demandes de maintenance et aux interventions dans une seule application simple à utiliser.

---

## 🎯 Problème identifié

La gestion de plusieurs logements devient rapidement complexe lorsque les informations sont réparties entre des courriels, des messages, des documents, des notes personnelles et différents outils.

Cela peut entraîner :

- des demandes de locataires oubliées ;
- des délais de réponse importants ;
- un manque de suivi des interventions ;
- une difficulté à retrouver l’historique d’un logement ;
- une mauvaise visibilité sur les logements disponibles ou occupés ;
- une perte de temps dans les tâches administratives répétitives.

RentIA vise à offrir une vue centralisée de l’ensemble de la gestion locative.

---

## 💡 Solution proposée

RentIA permettrait au propriétaire ou au gestionnaire de visualiser rapidement l’état de son parc immobilier et d’accéder aux informations importantes de chaque logement.

L’application est pensée autour d’une interface simple permettant de suivre :

- les logements ;
- les locataires ;
- les baux ;
- les loyers ;
- les demandes et signalements ;
- les rendez-vous ;
- les interventions de maintenance ;
- les entrepreneurs ou intervenants ;
- l’historique des événements associés à chaque logement.

---

## 🗺️ Vue globale des logements

Une des fonctionnalités principales prévues est une vue visuelle des logements avec différents états.

Exemple :

- 🟢 logement disponible ;
- 🟠 logement nécessitant une action ou un suivi ;
- 🔴 problème ou intervention prioritaire ;
- ⚪ autre état / logement non disponible selon le contexte.

L’objectif est de permettre au gestionnaire d’identifier rapidement les éléments qui nécessitent son attention.

---

## 🔧 Gestion des demandes et interventions

Lorsqu’un locataire signale un problème, le gestionnaire pourrait :

1. consulter la demande ;
2. déterminer son niveau de priorité ;
3. planifier une intervention ;
4. assigner un entrepreneur ou un intervenant ;
5. suivre l’avancement ;
6. conserver l’historique de l’intervention.

L’entrepreneur aurait uniquement accès aux informations nécessaires à son intervention, par exemple :

- l’adresse du logement ;
- le problème à traiter ;
- la date et l’heure du rendez-vous.

---

## 👥 Utilisateurs concernés

RentIA est conçu autour de plusieurs acteurs :

### Propriétaire / Gestionnaire

- gérer les logements ;
- consulter les baux et les occupants ;
- suivre les loyers ;
- traiter les demandes ;
- organiser les interventions ;
- suivre l’état global du parc immobilier.

### Locataire

- consulter certaines informations liées à son logement ;
- signaler un problème ;
- suivre les rendez-vous et interventions ;
- retrouver les informations importantes liées à son bail.

### Futur locataire

- consulter les informations pertinentes concernant un logement disponible ;
- suivre certaines étapes du processus de location.

### Entrepreneur / Intervenant

- recevoir les informations nécessaires pour effectuer une intervention ;
- connaître le problème, l'adresse et le rendez-vous associé.

---

## 🤖 Intelligence artificielle

À terme, RentIA pourrait intégrer des fonctionnalités basées sur l’intelligence artificielle afin de faciliter certaines tâches de gestion.

Quelques pistes étudiées :

- classification automatique des demandes ;
- aide à la priorisation des problèmes ;
- génération ou suggestion de réponses ;
- résumé de l’historique d’un logement ;
- recherche intelligente dans les informations du parc immobilier ;
- automatisation de certaines tâches administratives.

L’intelligence artificielle est envisagée comme un outil d’assistance au gestionnaire et non comme un remplacement de sa prise de décision.
