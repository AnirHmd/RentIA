# Acteurs métier

## Objectif

Ce document identifie les principaux acteurs qui interviennent dans le domaine de la gestion immobilière résidentielle. Il décrit leur rôle, leurs responsabilités et leurs interactions avec les autres acteurs du domaine.

L'objectif est de comprendre l'écosystème métier avant de définir les fonctionnalités du système.

---

# Vue d'ensemble

Les acteurs sont répartis en deux catégories :

- **Acteurs principaux** : participent directement à la gestion quotidienne des logements.
- **Acteurs secondaires** : interviennent de façon ponctuelle ou dans des situations particulières.

---

# Acteurs principaux

## 1. Propriétaire (Locateur)

### Description

Le propriétaire est l'acteur principal du domaine métier.

Il possède un ou plusieurs logements qu'il met en location et assure la gestion quotidienne de son parc immobilier.

### Responsabilités

- Administrer les logements.
- Publier les logements disponibles.
- Fixer le prix des loyers.
- Organiser les visites.
- Sélectionner les candidats.
- Préparer et signer les baux.
- Planifier les remises de clés.
- Répondre aux demandes des locataires.
- Organiser les réparations.
- Coordonner les entrepreneurs.
- Conserver les documents importants.
- Assurer le suivi de chaque logement.

### Interactions

Le propriétaire communique principalement avec :

- les locataires;
- les candidats locataires;
- les entrepreneurs;
- les prestataires de services;
- les organismes externes.

---

## 2. Gestionnaire

### Description

Le gestionnaire est une personne autorisée à administrer un ou plusieurs logements au nom du propriétaire.

Il peut s'agir d'un employé, d'un associé, d'un membre de la famille ou d'une personne mandatée temporairement.

### Responsabilités

- Assurer la gestion quotidienne des logements.
- Effectuer le suivi des demandes.
- Organiser les interventions.
- Communiquer avec les locataires.
- Représenter le propriétaire en son absence.

### Interactions

Le gestionnaire interagit avec les mêmes acteurs que le propriétaire selon les autorisations qui lui sont accordées.

---

## 3. Locataire

### Description

Le locataire est la personne qui occupe un logement en vertu d'un bail.

### Responsabilités

- Respecter les conditions du bail.
- Payer le loyer.
- Signaler les problèmes.
- Communiquer avec le propriétaire ou le gestionnaire.
- Informer de tout changement important.

### Interactions

Le locataire échange principalement avec :

- le propriétaire;
- le gestionnaire;
- les entrepreneurs lors d'interventions.

---

## 4. Candidat locataire

### Description

Le candidat locataire est une personne intéressée par la location d'un logement.

Il devient locataire après acceptation de sa candidature et la signature d'un bail.

### Responsabilités

- Demander des informations.
- Participer aux visites.
- Fournir les documents demandés.
- Signer le bail en cas d'acceptation.

### Interactions

Le candidat échange principalement avec :

- le propriétaire;
- le gestionnaire.

---

## 5. Entrepreneur

### Description

L'entrepreneur est un professionnel mandaté pour effectuer une intervention ou une réparation.

### Responsabilités

- Réaliser les travaux demandés.
- Respecter les rendez-vous fixés.
- Informer de l'avancement des travaux.
- Signaler les problèmes rencontrés.

### Interactions

L'entrepreneur communique avec :

- le propriétaire;
- le gestionnaire;
- le locataire lorsque sa présence est nécessaire.

---

# Acteurs secondaires

## 6. Prestataire de services

### Description

Entreprise ou professionnel réalisant des opérations d'entretien ou d'inspection périodiques.

### Exemples

- inspection des systèmes d'alarme;
- inspection des détecteurs de fumée;
- nettoyage;
- déneigement;
- entretien préventif.

---

## 7. Organismes externes

### Description

Organismes pouvant intervenir dans certaines situations administratives, juridiques ou financières.

### Exemples

- Tribunal administratif du logement (TAL);
- compagnies d'assurance;
- banques;
- municipalités;
- fournisseurs de services publics.

Ces organismes ne participent pas directement à la gestion quotidienne des logements, mais peuvent influencer certaines décisions ou obligations du propriétaire.

---

# Relations entre les acteurs

Le propriétaire constitue le point central de la gestion immobilière.

Tous les autres acteurs interagissent directement ou indirectement avec lui afin d'assurer le bon fonctionnement du parc immobilier.

Les échanges concernent principalement :

- la location des logements;
- les communications;
- les interventions;
- les rendez-vous;
- les documents;
- le respect des obligations contractuelles.

---

# Conclusion

La gestion immobilière repose sur la collaboration de plusieurs acteurs ayant des responsabilités complémentaires.

La bonne coordination de ces intervenants est essentielle afin d'assurer une gestion efficace des logements, un suivi rigoureux des demandes et une expérience satisfaisante pour les locataires.
